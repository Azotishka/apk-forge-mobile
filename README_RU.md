# APK Forge Mobile

Отдельный Android-проект; старый сайт APK Forge не изменяется.

## Версия 0.1.0
- Нативный интерфейс на русском языке.
- Выбор ZIP через системный файловый менеджер.
- Анализ структуры HTML/CSS/JS и Android Gradle-проектов.
- Защита анализа от ZIP больше 100 МБ, более 5000 файлов и очевидных путей с выходом из каталога.
- Импортированный код не запускается.

## Получение APK с телефона
1. Открой вкладку Actions в этом репозитории.
2. Выбери workflow **Build APK Forge Mobile** и нажми **Run workflow** (или дождись запуска после commit).
3. Открой завершённый запуск.
4. В Artifacts скачай `apk-forge-mobile-debug-apk`.
5. Распакуй скачанный ZIP и установи APK.

## Текущие ограничения
Это первая проверяемая версия анализатора, а не полноценный локальный компилятор других приложений. Встроенной локальной среды JDK + Gradle + Android SDK пока нет. Следующие этапы: безопасная распаковка и предпросмотр сайта, генерация WebView wrapper APK, затем анализ и запуск сборок Gradle через подтверждаемый runner. Полностью локальная компиляция на Android будет добавлена только после проверки совместимости.
